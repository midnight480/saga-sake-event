## 公開するとき

### Environment Variables に `5 Detected` と出る

異常ではありません。Vercel が `.env.example` を読んで変数名を拾っただけです。
**値は空のまま進めてください。** 必要な値は STEP 3・STEP 4 で自動的に入ります。

### `A repository named "saga-sake-event" already exists.` と出る

すでにこのリポジトリを持っている方が、README の Deploy ボタンを押すと出ます。
あのボタンは「リポジトリを自分のアカウントに複製する」ためのものなので、
同じ名前が 2 つ作れずに止まっています。

**名前を変えて進めないでください。** 別のコピーができてしまい、元のリポジトリを
更新してもサイトに反映されなくなります。

代わりに <https://vercel.com/new> を開き、「Import Git Repository」の一覧から
`saga-sake-event` を選んで **Import** してください。
（[デプロイ手順 STEP 2-B](デプロイ手順.md)）

### Application Preset が `Other` になっている

**違うリポジトリを取り込もうとしています。**

正しいリポジトリなら、Vercel が自動で `Next.js` を検出します。
Deploy を押す前に、画面の「Importing from GitHub」が
**`midnight480/saga-sake-event`**（`sake` が入っている方）になっているか
確かめてください。

`saga-event-space` という名前のよく似たリポジトリがありますが、これは
別のプロジェクトです。

### 違うリポジトリを Deploy してしまった

Vercel の **Settings** → **General** → いちばん下の **Delete Project** で
そのプロジェクトを消してから、正しいリポジトリで作り直してください。
GitHub 側のリポジトリは消えません。

## 設定・公開について

### 「Storage」や「Integrations」が見つからない

**画面の上ではなく、左を見てください。**

Vercel のプロジェクト画面は、左側にメニューが縦にならんでいます。
「Storage」と「Integrations」はその中ほどにあります。

```
saga-sake-event
 ├ Overview
 ├ Deployments
 ├ Logs
 ├ Analytics
 │   …
 ├ Integrations   ← Clerk を入れるのはここ
 ├ Storage        ← Neon を入れるのはここ
 ├ Flags
 │   …
 └ Settings
```

Vercel のトップ画面（プロジェクトの一覧）には出てきません。
必ず **`saga-sake-event` を開いてから**探してください。

### 「はじめの設定」の画面から先に進めない

設定を追加したあと、**画面を再読み込み**してください。
それでも変わらない場合、Vercel がまだサイトを作り直している途中です。
1〜2 分待ってもう一度開いてください。

Vercel の **Deployments** タブで、いちばん上のものが **Ready**（緑）に
なっているか確認できます。**Building**（黄色）なら、まだ途中です。

### データベース（Neon）が「✓」にならない

Neon が**このプロジェクトに接続されていない**ことが多いです。

1. Vercel の **Storage** タブを開く
2. 作った Neon を押す
3. **Projects** タブで `saga-sake-event` が並んでいるか確認
4. 無ければ **Connect Project** で追加する

追加したあと、Vercel が自動でサイトを作り直します（1〜2 分）。

### ログイン（Clerk）が「✓」にならない

同じく、**このプロジェクトに接続されていない**可能性があります。

1. <https://vercel.com/marketplace/clerk> を開いて **Install** を押す
2. 接続先として `saga-sake-event` を選ぶ

すでに入れてある場合は、Vercel の **Settings → Environment Variables** に
`CLERK_SECRET_KEY` と `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` の 2 つが
並んでいるか確認してください。

## 主催者アカウントについて

### 自分ではない人が主催者になってしまった

「最初にログインした人が主催者」という仕組みのためです。
次の操作で、ご自身を主催者に指定できます。

1. Vercel の **Settings** → **Environment Variables**
2. **Key** に `ORGANIZER_EMAILS`
3. **Value** にご自身のメールアドレス
   （複数指定するときはカンマ区切り: `a@example.com,b@example.com`）
4. **Save** を押す
5. **Deployments** タブ → いちばん上の「⋯」→ **Redeploy**

作り直しが終わったら、そのメールアドレスでログインしてください。

### 運営画面を開こうとすると参加者の画面に飛ばされる

その人は主催者として登録されていません。上の手順で
`ORGANIZER_EMAILS` にメールアドレスを追加してください。

## 酒蔵のログインについて

### 「ログインアカウントを作れませんでした」と出る

Clerk 側で **Username（ユーザー名）でのログイン**が無効になっています。

1. <https://dashboard.clerk.com> を開く
2. 左メニュー **User & Authentication** → **Email, Phone, Username**
3. **Username** のスイッチを **オン**
4. **Password** のスイッチも **オン** になっているか確認

そのあと、蔵アカウントの一覧で **「パスワードを再発行する」** を押すと、
ログインアカウントが作られます。

### 酒蔵がパスワードをなくした

蔵アカウントの一覧で、その蔵の **「パスワードを再発行する」** を押してください。
新しいパスワードがその場で表示されます。**古いパスワードは使えなくなります。**

### パスワードをもう一度見たい

**表示できません。** このアプリはパスワードを保存していないためです
（万一情報が漏れても、蔵のログインが使われないようにするための設計です）。

「パスワードを再発行する」で新しいものを出してお渡しください。

## チケットについて

### 参加者が「この券はすでに読み取り済みです」と言われる

その紙はもう使われています。**別の紙**を渡してください。
同じ QR を 2 人が使えないようにする仕組みが働いています。

### 参加者が「この券は登録されていません」と言われる

- 券コードを手で入力して打ち間違えた → もう一度確かめる
- ほかのイベントの紙が混ざっている → 正しい紙を渡す
- データベースを作り直した → 発行済みの紙はすべて無効です。刷り直してください

### 当日券が「完売」になった

**チケットQR** タブの **「＋50枚 発行」** を押してください。
その場で販売を再開できます。追加した分の紙は「印刷用ページ」から印刷します。

ダッシュボードに金色の警告が出ているときは、その中のボタンから
100 枚まとめて発行できます。

### 前売券が 0 枚のまま何もできない

前売券は**仕様として追加発行できません**（事前に発行済みの券を表す枠だからです）。
当面は **当日券だけで運用**できます。前売を扱うなら、前売の販売数が決まった
時点で、開発者に前売券の発行を有効化してもらってください。

## 参加者のスマホについて

### カメラが起動しない / 真っ黒

1. **「カメラでQRを読み取る」ボタンを押したか**確認する
   （勝手には起動しません）
2. ブラウザがカメラの使用許可を求めたら **「許可」** を押す
3. 一度「許可しない」を押してしまった場合:
   - **iPhone (Safari)**: 設定アプリ → Safari → カメラ → 「確認」または「許可」
   - **Android (Chrome)**: アドレスバー左の鍵マーク → 権限 → カメラ → 許可
4. どうしても動かない場合は、**画面の下の欄に券の文字列を手で入力**できます。
   紙に書かれている `SAGA-DAY-XXXXXXXXXX` をそのまま入れてください

### 画面が勝手に拡大する / 文字が小さい

拡大は禁止していないので、指で広げて読めます。
入力欄をタップしたときに勝手に拡大することはありません。

### 通信が不安定です、と黄色い帯が出る

会場の電波が弱いときに出ます。**表示されている数字は少し前のもの**です。
電波の良い場所へ移ると自動で最新になります。操作自体は届いていれば反映されます。

### アプリのように使いたい

ブラウザの共有メニューから **「ホーム画面に追加」** を選ぶと、
アイコンから開けるようになります。iPhone でも Android でも使えます。

## それでも解決しないとき

Vercel の **Logs** タブに、エラーの内容が記録されています。
開発者に相談するときは、次の 3 つを伝えてください。

1. **何をしたか**（どのボタンを押したか）
2. **何が出たか**（画面に出た文字をそのまま）
3. **Logs タブの赤い行**（あれば、その文面）

`/setup` 画面の各項目にある **「技術的な詳細（開発者向け）」** を開くと、
原因の手がかりが出ています。あわせて伝えると早く解決します。
