# 当日の運営手順

事前の準備（[デプロイ手順](デプロイ手順.md)の STEP 6）が終わっている前提です。

---

## 前日までに

- [ ] 各酒蔵に **蔵ID とパスワードの紙**を渡した
- [ ] 各酒蔵に「**当日、開場前に持ち込む銘柄と本数を登録してください**」と伝えた
- [ ] **チケットQR を印刷**して用意した
- [ ] 会場入口に貼る **URL の QR コード**を用意した
- [ ] 関係者に多めに配るなら、券種ごとのポイントを決めた（下記）
- [ ] **利用規約とプライバシーポリシーに目を通した**（`/terms`・`/privacy`。下記）

### 利用規約とプライバシーポリシー

参加者と酒蔵は、最初にログインしたときに、この 2 つへの同意を求められます。

- 事業者は「本イベントの主催者」、連絡先は「アプリ内の問い合わせ」と書いてあります。
  実際の運営と合っているかを確かめ、**必要なら弁護士などの専門家に見てもらってください**
- 本文を直した場合は、開発を手伝っている人に「`src/lib/legal.ts` の版を上げてほしい」と
  伝えてください。上げると、全員にもう一度同意を求めます

### 関係者に多めに配りたいとき

参加者のポイントは、**受付で渡す券の種類**で決まります。本人が選ぶ画面は
ありません。

関係者に多めに配りたい場合は、**前売券のポイントを多めに設定して、その券を
関係者に渡す**のがいちばん簡単です（イベント設定の画面で券種ごとに決められます）。

```
前売券   15 ポイント   → 関係者に渡す
当日券   10 ポイント   → 一般の来場者に渡す
```

## 開場前（1〜2 時間前）

### 1. 酒蔵に登録してもらう

各蔵の担当者に、スマホで URL を開いてもらい、配った **蔵ID とパスワード**で
ログインしてもらいます。

そのあと **「持ち込み登録」** タブで:

- 銘柄名を入れる
- 種類を選ぶ（精米歩合とチケット枚数が自動で入ります）
- 瓶のサイズを選ぶ（**四合瓶 = 6 杯 / 一升瓶 = 15 杯** で換算）
- 「この銘柄を登録する」
- そのあと **本数**を ＋ボタンで入れる

→ 提供できる杯数が自動で出ます。

### 2. 主催者が確認する

**ダッシュボード**を開いて:

- 「出展蔵」が予定どおりの数になっているか
- 「残り在庫」が 0 でないか（0 なら、どこかの蔵が本数を入れていません）
- 蔵別の一覧で「この蔵はまだ銘柄を登録していません」が出ていないか

登録が遅れている蔵があれば、その場で声をかけてください。

### 3. 受付にチケットQR を置く

印刷した QR の紙を、券種ごとに分けて受付に置きます。
**お金のやりとりはこのアプリでは扱いません。** 受付で代金を受け取ったら、
紙を 1 枚渡してください。

---

## 開場（開始時刻）

主催者の **「イベント設定」** タブ →
**「イベントを開始する（受付解禁）」** を押します。

**これを押すまで、参加者はリクエストを送れません。**
押すと画面右上が「開始前」から「開催中」に変わります。

> 開始時刻より前に押しても、時刻になるまで注文は通りません。
> 安心して少し早めに押しておけます。

---

## 開催中 ─ 主催者が見るところ

**ダッシュボード**を開いたままにしておきます。4 秒ごとに自動で更新されます。

### 上の 6 つの数字

| 数字 | 見方 |
| --- | --- |
| 出展蔵 | 登録済 / 予定 |
| 残り在庫 | 会場全体で、まだ注げる杯数 |
| **販売できる当日券** | **0 になったら要注意**（下記） |
| 前売 未読取 | 配った前売券のうち、まだ読み取られていない枚数 |
| 受渡完了 | 今日お渡しした件数 |
| 対応待ち | 蔵がまだ片付けていない件数 |

### 金色の警告：「チケットだけが売り切れています」

**当日券が 0 枚なのに、会場にはまだ注げる酒がある**状態です。
このまま放っておくと、お酒が余っているのに来場者が何も飲めません。

→ 警告の中の **「当日券を100枚 追加発行する」** を押してください。
すぐに販売を再開できます。**押した直後から参加者の画面も使えるようになります。**

追加した分の QR は、**チケットQR タブの「印刷用ページ」**から印刷できます。

### 赤い警告：「応答遅延アラート」

ある蔵が、注文を受けたまま **12 分以上** 何もしていない状態です。

蔵の担当者が
- 画面を見ていない
- 忙しくて手が回っていない
- ログアウトしてしまった

のどれかです。**その蔵に直接見に行ってください。**

### 蔵別の一覧

- **残量バー**が赤（20% 未満）になった蔵は、そろそろ品切れです
- **「混雑」**が出ている蔵は待ちが 3 件以上あります。会場アナウンスで
  空いている蔵に誘導すると流れがよくなります
- **「受付停止中」**は、その蔵が自分で受付を止めています

## 開催中 ─ 酒蔵の操作

**「受付キュー」** タブを開いたままにしておきます。

注文が入ると上に並びます。1 件ずつ:

```
受付済  →  [準備中にする]  →  準備中  →  [準備完了にする]  →  準備完了
        →  [受渡完了]  →  完了
```

- **「受渡完了」を押した瞬間に、在庫が減ります。** お渡ししてから押してください
- 参加者が自分の画面で **「受け取りました」** を押しても受渡完了になります。
  お渡しするときに参加者の画面を見せてもらい、その場で押してもらうと、
  取り違えに気づけます（スマホの操作が難しい方は、蔵の「受渡完了」で構いません）
- 準備完了のまま取りに来ない人には **「催促する」**。参加者のスマホにもう一度
  知らせが届きます（1 分に 1 回まで）
- 押し間違えたら **「キャンセル」**。参加者のチケットは戻ります
- 手が回らなくなったら **「新規リクエストを一時停止する」**。
  参加者の画面に「受付停止中」と出て、新しい注文が来なくなります。
  落ち着いたら「受付を再開する」

**参加者の画面の文言は、蔵がボタンを押すたびに変わります。**
「準備中にする」を押せば、参加者には「いま注いでいます」と出ます。

---

## 開催中 ─ 参加者の流れ

1. 会場入口の QR から URL を開く
2. メールアドレスで登録（届いた数字を入れるだけ）
3. **「券の QR を読み取る」** → 受付でもらった紙の QR を読み取る → ポイントが入る
4. **「酒蔵をさがす」** → 混雑・残り・必要なポイントを見て行く先を決める
5. ブースの前で銘柄と杯数を選んで **リクエスト**
6. **「マイページ」** で状況を見る。「ブースで受け取ってください」と出たら取りに行く
7. ブースで受け取ったら、蔵の人に画面を見せて **「受け取りました」** を押す

### 参加者が困ったときの答え

| 言われること | 答え |
| --- | --- |
| QR をどこから読むのか分からない | スマホの**カメラ**を開いて券の QR に向け、出てきた案内を押します。アプリの中なら、上のメニューの「チケット」を開くと読み取り枠が出ます |
| カメラが動かない | 「チケット」画面の下の欄に、券の文字列を手で入力できます |
| アプリを閉じていると通知が来ない（iPhone） | ホーム画面に追加し、**そのアイコンから開いて**ヘルプの「お知らせを受け取る」を押す必要があります |
| 「すでに読み取り済みです」と出る | その券はもう使われています。別の紙を渡してください |
| 「チケット不足」と出る | 受付で券を追加してもらってください |
| 「開始前」と出る | 主催者が「イベントを開始する」を押していません |
| 「完売」と出る | その銘柄は終了です。ほかを選んでもらってください |

---

## 閉場

主催者の **「イベント設定」** → **「イベントを終了する」**

押すと新しい注文を受け付けなくなります。
**まだ「準備中」「準備完了」の注文が残っていないか**、ダッシュボードの
「対応待ち」で確認してから押してください。

---

## 終わったあと

データはそのまま残ります。ダッシュボードの「受渡完了」件数や、
蔵別の残り在庫が、そのまま実績の記録になります。

次回のイベントで使い回すときは、Vercel の画面で Neon のデータベースを
新しく作り直すか、蔵と銘柄を登録し直してください。
